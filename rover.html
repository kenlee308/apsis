Camera Rover

A Wi-Fi camera rover built from scratch that follows people using computer vision.

  • Arduino Uno as the motor brain
  • ESP32-CAM as the Wi-Fi camera bridge
  • PC-side vision with MediaPipe person-follow (body or face)
  • Custom HTTP and serial protocol tying it together
  • PC control app with joystick driving and live tuning

Coming next: a room-scan map from a sweeping distance sensor.

The code is private.
